# Lost & Found
교내 분실물 문제를 개선하기 위한 웹사이트입니다.

학교에서 잃어버린 분실물을 찾기 위한 학교 인스타그램 계정이 이미 있지만 시험기간이나 인스타그램을 사용하지 않는 학생들은 제한이 있을 수 있습니다.
또한 그 계정이 오직 분실물만을 위한 계정이 아닌지라 분실물 외 다른 주제의 글이 올라오는 경우도 적지 않습니다.
이런 점을 보고 교내 분실물을 제대로 관리하기에 현재 방식에는 무리가 있구나 싶어 분실물을 관리하기 위한 사이트, Lost % Found를 개발하게 되었습니다.

이전에 개발했던 공생 웹사이트 때 바닐라 JS를 썼어서 이번에도 자연스럽게 바닐라로 진행했습니다.



api키를 노출하는 바람에 비공개로 올렸었다가 커밋 내역을 삭제할 수 있다는 걸 알게 되어서 키를 삭제하고 공개로 올립니다.
